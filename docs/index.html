WBS↔LINK maps schedule activities and cost structures to a common Work Breakdown Structure, and surfaces the links that need review.

Map. Review. Reuse.

MAPDesigned to propose the relationship between each schedule activity or cost line and the WBS.
REVIEWDesigned to surface uncertain links for a person to confirm rather than quietly assuming them.
REUSEDesigned to carry approved relationships into later reporting cycles, with checks for structural change.

The WBS↔LINK Challenge

A synthetic project, three monthly reporting cycles. Map the schedule and cost structures back to the WBS with Excel, SQL, Python, AI, or your own method. Then see how your approach scores.

  1. Download the synthetic project files. The practice set includes its answers.
  2. Map each schedule activity and cost line, plus supporting contractor records, to a WBS element, or mark it NO_WBS, NEW_SCOPE or UNSURE. The challenge README defines each answer and the required record IDs.
  3. Don't guess. UNSURE is an honest answer.
  4. Practice first. Practice is repeatable. The hidden Challenge set allows one scored attempt per GitHub user.
  5. Score: a published trust-weighted score rewards supported mappings and penalizes confident wrong mappings most heavily.

A missing mapping creates a question. A confident wrong mapping creates a reporting risk.
