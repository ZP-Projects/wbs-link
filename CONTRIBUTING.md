# Contributing

Thank you for helping improve how schedule, WBS and cost structures connect.

- **Patterns** (via the "Share a real-world pattern" form): describe the *pattern*, never the project. No client, employer, project or person names, codes or values.
- **Improvements to the scorer or site:** open a pull request. By contributing, you certify the Developer Certificate of Origin (https://developercertificate.org/): sign off commits with `git commit -s`. Your contribution is licensed under this repository's licences.
- **Never submit real or confidential data.** Submissions that appear to contain it will be deleted.
- Be respectful; see CODE_OF_CONDUCT.md.
